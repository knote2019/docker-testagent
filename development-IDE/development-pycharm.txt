配置 pycharm:
1. disable new UI and create default project.
2. disable AI related plugins.
3. import color scheme.
   /tmp/pycharm-color-scheme-2024-04-24.icls
4. install eclipse keymap plugin and set as this keymap.
5. install file watchers plugin and configure yapf.
   /usr/local/bin/yapf
   -i $FileName$
   $FileName$
6. setting->editor->general->code folding 去除所有勾选.
7. setting->editor->inlay hints  去除所有勾选.
8. reopen IDE, close welcome reminder.
