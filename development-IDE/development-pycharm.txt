configure chrome:
   https://netron.app

configure pycharm:
1. disable new UI and create default project.
2. disable AI related plugins.
3. install eclipse keymap plugin and set as this keymap.
4. install file watchers plugin and configure yapf.
   /usr/local/bin/yapf
   -i $FileName$
   $FileName$
5. install Dracula VSCode plugin to set color scheme.
6. setting->editor->general->code folding # remove all choose option
7. setting->editor->inlay hints           # remove all choose option
8. reopen IDE, close welcome reminder.
