配置 clion:
1. disable new UI and create default project.
2. disable AI related plugins.
3. import color scheme.
   http://10.113.3.1/corex/toolbox/ide/clion-color-scheme-2024-04-24.icls
4. install eclipse keymap plugin.
5. install file watchers plugin and configure clang-format.
   /usr/bin/clang-format
   -i $FileName$ --style=file
   $FileName$
6. setting->editor->code folding 去除所有勾选.
7. setting->editor->inlay hints  去除所有勾选.
8. reopen IDE, close welcome reminder.
9. configure chrome.
   https://www.baidu.com
   https://netron.app
