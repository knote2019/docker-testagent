配置 clion:
1. create default project and set python.
2. install eclipse keymap plugin.
3. install file watchers plugin and configure yapf.
   // /usr/local/bin/yapf
   // -i $FileName$
   // $FileName$
4. 参考configure-pycharm.
5. reopen pycharm, close welcome reminder.
6. 配置浏览器，加入https://www.baidu.com,https://netron.app等到收藏栏.
