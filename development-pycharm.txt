配置 pycharm:
1. disable AI related plugins.
2. import color scheme.
   http://10.113.3.1/corex/toolbox/ide/pycharm-color-scheme-2024-04-24.icls
3. create default project.
4. install eclipse keymap plugin.
5. install file watchers plugin and configure yapf.
   // /usr/local/bin/yapf
   // -i $FileName$
   // $FileName$
6. setting->editor->code folding 去除所有勾选.
7. setting->editor->inlay hints  去除所有勾选.
8. reopen pycharm, close welcome reminder.
9. configure chrome.
   // https://www.baidu.com
   // https://netron.app
