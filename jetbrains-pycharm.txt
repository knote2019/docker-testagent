配置 pycharm:
1. create default project and set python.
2. install eclipse keymap plugin.
3. install file watchers plugin and configure yapf.
   // /usr/local/bin/yapf
   // -i $FileName$
   // $FileName$
4. setting->editor->code folding 全部去掉勾选.
5. setting->editor->inlay hints 全部去掉勾选.
6. reopen pycharm, close welcome reminder.
7. 配置浏览器，加入https://www.baidu.com,https://netron.app等到收藏栏.
